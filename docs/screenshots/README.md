# Screenshots

Captured from the running app against a **synthetic demo record**
("Northwind Field Record"). The places are real; the events, documents, and
person are not. No real location, token, or personal record is shown.

| File | What it shows |
|---|---|
| `overview.png` | Overview: places, live position, recent activity, documents, open tasks, local service health. |
| `timeline.png` | Timeline editor with the week's events and the Beacon timeline. |
| `knowledge-base.png` | Knowledge base: entities, locations, and sources. |
| `narrative.png` | Narrative builder: the tiered field narrative and scene list. |
| `sousveillance-map.png` | Sousveillance map: project locations, route/track, and the local map services panel. |
| `tasks.png` | Tasks grouped by status and area. |
| `phone-home.png` | SkeletonKey Beacon on Android: live fix, link status, ambient stream, and an HQ message. |
| `phone-settings.png` | Beacon settings: server URL, token, encryption key, and on-device voice options. |
| `about-support.png` | Settings → About & support: the donation options and copy buttons. |

The desktop captures are 1440×900, except `about-support.png`, which is the
full 2880×1800 (2×) capture. The phone images are 1080×1920 from an Android
emulator.
